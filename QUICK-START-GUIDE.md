# 🎯 Quick Start Guide for LeetCode Practice

> **Your workflow for effective practice sessions**

---

## 📋 Before Each Practice Session (5-10 minutes)

### Step 1: Review the Cheat Sheet 🚀
Open **[ALGORITHMS-CHEATSHEET.md](./ALGORITHMS-CHEATSHEET.md)** and scan through:

1. **Time Complexity Table** - Refresh your understanding
2. **Common Patterns** - Identify which patterns you'll likely use
3. **Code Templates** - Glance at the implementations

**Pro Tip**: Don't try to memorize everything. Just familiarize yourself with what's available so you can refer back when needed.

---

## 💻 During Practice

### Step 2: Problem Analysis
Use **[README.md](./README.md)** checklist:

- ✅ Understand the problem
- ✅ Identify constraints 
n <= 12   - O(n!)
n <= 25   - O(2^n)
n <= 100  - O(n^4)
n <= 500  - O(n^3)
n <= 10^4 - O(n^2)
n <= 10^6 - O(nlogn)
n <= 10^8 - O(n)
n > 10^8  - O(logn) or O(1)


- ✅ Think through strategy
- ✅ Write pseudocode

### Step 3: Pattern Recognition
Ask yourself:
- Is this a **Two Pointers** problem? (sorted, pairs, palindromes)
- Is this a **Sliding Window** problem? (subarray, substring)
- Do I need a **Hash Map**? (frequency, duplicates)
- Is it a **Stack** problem? (parentheses, next greater)
- Should I use **Binary Search**? (sorted, search space)
- Is it a **DP** problem? (optimal substructure)
- Is it a **Graph/Tree** problem? (connected, paths)

### Step 4: Refer to Cheat Sheet
When you identify the pattern:
1. Go to that section in **ALGORITHMS-CHEATSHEET.md**
2. Review the template code
3. Adapt it to your specific problem

### Step 5: Code & Test
- Start with a simple working solution
- Test with edge cases
- Optimize if needed

---

## 📚 After Practice Session

### Step 6: Review & Learn

## 🔄 Typical Workflow Example

```
1. Start → Open ALGORITHMS-CHEATSHEET.md
2. Scan patterns (2 mins)
3. Pick a LeetCode problem

5. Identify pattern → "This looks like Two Pointers"
6. Refer to cheat sheet → Review two pointers template

8. Test → Edge cases
9. Submit → ✅

```

## 🎓 Study Tips

### For Beginners
1. Start with **Easy** problems
2. Focus on **one pattern per day**
3. Type out solutions from cheat sheet to build muscle memory
4. Don't rush - understanding > speed

### For Intermediate
1. Mix **Easy** and **Medium** problems
2. Try to solve without looking at cheat sheet first
3. Time yourself (30-45 mins per problem)
4. Focus on optimization

### For Advanced
1. Focus on **Medium** and **Hard** problems
2. Minimize cheat sheet usage
3. Strict time limits (20-30 mins)
4. Focus on multiple solutions per problem

---

## 🏆 Remember

> **"The cheat sheet is a reference, not a crutch"**

The goal is to:
1. **Familiarize** yourself with patterns
2. **Recognize** them quickly in new problems
3. **Adapt** templates to specific scenarios
4. **Internalize** the logic through practice

With consistent practice, you'll naturally remember the patterns and won't need the cheat sheet as often!
