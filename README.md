## ✅ Before You Code (Problem Analysis)

- [ ] 🔍 **Understand the Problem**
  - [ ] Can I rephrase the question in my own words?
  - [ ] What are the inputs and expected outputs?
  - [ ] Are there example cases given?

- [ ] 📏 **Identify Constraints**
  - [ ] What is the input size (e.g., n ≤ 10^5)?
  - [ ] Any constraints on time or space complexity?
  - [ ] Can input be negative, null, or empty?

- [ ] 🧠 **Think Through Strategy**
  - [ ] Is brute force possible? Efficient?
  - [ ] Any keywords hinting Binary Search, Hashing, Sliding Window, etc.?
  - [ ] Can sorting help reduce time complexity?

- [ ] ✍️ **Write Pseudocode**
  - [ ] What variables will I use?
  - [ ] What loops or conditions are needed?
  - [ ] What is the base case (for recursion)?
  - [ ] Write a dry-run of the logic with sample data.

---

## ✏️ While Coding

- [ ] 🧼 **Start Simple**
  - [ ] Follow pseudocode closely.
  - [ ] Use clear and consistent variable names.
  - [ ] Log variables if needed (`console.log()` / `print()` / `debugger`)

- [ ] 🚧 **Handle Edge Cases**
  - [ ] Empty input?
  - [ ] All elements same?
  - [ ] Only one element?
  - [ ] Already sorted or reverse sorted?

---

## 🧪 After Code Is Written

- [ ] 🧰 **Test with Multiple Cases**
  - [ ] Basic case ✅
  - [ ] Edge cases ✅
  - [ ] Large inputs ✅
  - [ ] Randomized case ✅

- [ ] 🪛 **Debug & Trace**
  - [ ] Add print logs to trace execution
  - [ ] Use debugger or visualizer (e.g., [PythonTutor.com](https://pythontutor.com))

- [ ] 📈 **Check Complexity**
  - [ ] Time complexity: O( ? )
  - [ ] Space complexity: O( ? )

- [ ] 🧽 **Refactor**
  - [ ] Rename unclear variables
  - [ ] Remove unnecessary code
  - [ ] Add helpful comments (especially for recursion/base cases)
